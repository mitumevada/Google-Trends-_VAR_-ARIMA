## Google Trend Time Series Analysis

### Project Title
Bitcoin vs Crypto Crash: A Time Series Analysis using VAR and SARIMA Models.

## Objective
The objective of this project is to analyze and forecast the relationship between Google search trends for "Bitcoin" and "Crypto Crash".

The analysis includes: 
- Stationarity testing using ADF test
- Granger causality analysis
- VAR model for multivariate forecasting
- SARIMA models for univariate forecasting
- Comparison of forecasting performance

## Data Source
- Google Trends data
- Extracted using the pytrends Python Library
- Time Period: Last 5 Years 

## Current Progress

- Stationarity tested using ADF
- Granger causality analyzed
